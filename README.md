# コードスペースレベル1

このレベルでは、<span class="info">統合開発環境（IDE）</span>の1つである、`GitHub Codespaces`の、基本的な利用方法を学びます。ブラウザさえあれば、環境構築の手間なく、すぐにプログラミングを始められることが、`Codespaces`の大きな特徴です。

このレベルでは、`Codespaces`とは何かという基礎から出発し、実際に`Codespace`を起動し、画面の構成や初期設定を確認します。そのうえで、ファイルの作成や編集といった基本操作、拡張機能のインストール方法を学びます。さらに、`HTML/CSS`、`JavaScript`、`Python`、`Jupyter Notebook`という、異なる種類のファイルを編集する際に役立つ、それぞれの拡張機能や画面の使い方を、実際に触れながら確認していきます。最後に、作業内容を記録し、`GitHub`と連携するための、最低限の操作も扱います。

このレベルは、あくまで`Codespaces`というエディタ自体の使い方を学ぶことが目的であり、`HTML`・`JavaScript`・`Python`といった、それぞれの言語自体の文法や書き方を学ぶものではありません。

## 内容
コードスペースレベル1では以下のテーマを取り扱います。

* コードスペースの概要
* 画面構成と設定
* 基本操作
* 拡張機能の利用
* HTML/CSSファイルの編集
* JavaScriptファイルの編集
* Pythonファイルの編集
* JupyterNotebookの編集
* Git/Githubとの連携

コードスペースの基本的な利用方法を紹介しますが、本カリキュラムでは上記の分野のみを取り扱います。

## 対象
コードスペースレベル1は以下のような方を対象にしています。

* 初めてプログラミングを学習する方

## 学習の前提条件
前提条件はありません。

## 学習用実行環境の前提条件
このカリキュラムでは、`Codespace`を利用していることを前提にしています。以下のような環境であれば、学習を進めることが可能です。

* 2026年9月時点の`Codespace`の機能、画面構成、デフォルトコンテナイメージに基づきます。
* `Codespace`で`Node.js`がインストールされている。
* `Codespace`で`Python`がインストールされている。
